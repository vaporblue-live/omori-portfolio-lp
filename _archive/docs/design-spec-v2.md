# デザイン指示書 v2：S.OMORI ポートフォリオLP

## 1. コンセプト
- **テーマ**：映画の祭典（授賞式）。作品が「ノミネート作」として、スポットライトの中に一つずつ現れる。
- **配色**：ブルーノート・レーベルのジャケットを意識する。
- **再現する動き**：参考動画の **PC画面の中の動きのみ**。ノートPC、キーボード、俯瞰のカメラなど、画面の外の要素は一切入れない。

## 2. 参考動画から再現する動き（画面内のみ）
| 要素 | 内容 | 実装 |
|------|------|------|
| 浮遊するガラスカード | 半透明のカードが、手前と奥に重なって浮かぶ | Three.js の平面＋半透明マテリアル |
| 視差 | カードごとに奥行きが違い、動くとずれて見える | カードごとに z 座標を変える |
| カードの切り替わり | タイトル入りのカードが順に正面へ来る | スクロール量に連動 |
| 螺旋状の出現 | 各セクションの情報が螺旋（らせん）を描いて手前に出てくる | カードを螺旋の軌道上に配置し、スクロールで回転 |
| 粒子 | 暗い背景に光の粒が舞う | Points（パーティクル） |
| 左のメニュー | 細い文字のメニューが並ぶ | HTML で重ねて表示 |

- スマホと「動きを減らす」設定の端末では、3Dを止めて、軽いフェードの切り替えに置き換える。

## 3. 配色（ブルーノート × 授賞式）
| 役割 | 色 | 用途 |
|------|----|------|
| 背景 | `#0a0a0c`（漆黒） | 全体の地 |
| メイン | `#1f4ea8` 前後のブルーノート・ブルー | 面、帯、カードの縁 |
| 文字 | `#f5f1e8`（オフホワイト） | 本文・見出し |
| アクセント | `#c9a24a` 前後のゴールド | 授賞式の象徴として、要所だけに使う |

- ブルーノートのジャケットのように、**大きな色面と、太い文字の対比**で構成する。
- ゴールドは「ノミネート」「受賞」を連想させる箇所に限定する。

## 4. タイポグラフィ
- **書体は1ファミリーに統一する**：日本語と英字の両方を含む `Noto Sans JP` を使う。
- 太さ（Black／Bold／Regular）と字間で強弱をつけ、書体を混ぜない。
- 文字サイズと余白は、引き続き黄金比（1:1.618）のスケールで統一する。

## 5. セクション別の修正内容
### Profile
- 漢字名を削除し、表記を **S.OMORI** にする。
- 写真のクロップ崩れを直し、正しい比率で表示する。写真と文章を横に並べ、右側の空きをなくす。
- 説明文に **ポストプロダクション** を加え、文章として自然につながるように書き直す。
- 「経験」「自分のチャンネルで公開」の説明を、意味と量のある文章に書き直す。
- 使用ソフトは、**ロゴと文字を並べて** 表示する。

### Pricing
- 各プランに **サムネイル枠** を設ける。
- 価格は **国内の動画編集の相場を調べて** 設定し、根拠を残す。

## 6. 守ること
- 事実に基づかない実績・数値は載せない。
- 外部ライブラリは固定バージョンで同梱する（CDNはこの環境から使えないため）。
- 公開先は `vaporblue-live/omori-portfolio-lp`（GitHub Pages）。
