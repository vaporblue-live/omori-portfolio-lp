# 要件定義書：動画編集ポートフォリオLP

## 1. 概要
- **サービス名**：動画編集ポートフォリオ（パーソナルブランド / クリエイター名は後日確定。仮置きで差し替え可能な設計にする）
- **コンセプト**：ブルーノート・レコーズのジャズ × ミッドセンチュリーの世界観。漆黒とディープブルー、くすんだゴールドで、シネマティックな編集のリズムと緩急を伝える。
- **種別**：3Dインタラクティブ・ポートフォリオLP（1ページ）

## 2. ターゲット
- 映像制作会社の担当者
- 大手企業のマーケティング担当者
- 新規プロジェクトのプロデューサー
- ウェディング・ブランドムービーを依頼したいクライアント

## 3. ゴール（CTA）
- ヘッダーとページ下部から「案件相談・お見積もり」へ遷移させる。
- 遷移先は問い合わせフォーム、カレンダー予約、メールリンクのいずれか（後日選択）。
- CTAは各セクションの終わりにも配置し、離脱を減らす。

## 4. 掲載セクション（想定順）
| No | セクション | 目的 | 主な要素 |
|----|-----------|------|---------|
| 1 | ヒーロー（FV） | 世界観の即時伝達 | キャッチコピー、3Dフィルムリール（ドラッグで回転） |
| 2 | 編集哲学 | 強みの言語化 | リズム・テンポ・映像美学の3項目 |
| 3 | フィーチャードワーク | 実績の提示 | 動画プレビュー付きの3D空間カードグリッド |
| 4 | クライアントの声・実績 | 信頼の補強 | 引用、実績数値、ロゴ |
| 5 | プロフィール | 人柄と経歴 | 写真、略歴 |
| 6 | お問い合わせ（CTA） | 成約導線 | 主要CTAボタン、補助リンク |

## 5. デザイン仕様
- **配色**
  - 漆黒：`#0a0a0c`（基調背景）
  - ディープブルー：`#0f172a`（セクション地）
  - くすんだゴールド：`#d97706`（アクセント。見出しの一部とCTAに限定）
- **タイポグラフィ**
  - 見出し：セリフ体（エディトリアル感）
  - 本文：サンセリフ体（可読性）
  - 字間・行間・余白は黄金比（1:1.618）に沿った間隔スケールで統一する。
- **余白**：引き算の美学。1画面に要素を詰め込まない。
- **テンプレート感の排除**：汎用的なカードUIやグラデーション過多を避ける。

## 6. 3D・モーション仕様
- **3D要素**：フィルムリール（ヒーロー）、空間カード（実績）を、マウス・タッチで回転・ドラッグ操作できるようにする。
- **実装**：Three.js を cdnjs から固定バージョンで読み込む。
- **モバイル**：3Dを停止し、CSSの軽量アニメーションに切り替える。
- **アクセシビリティ**：`prefers-reduced-motion` の端末では静的表示にする。
- **性能目標**：ページ表示時の3D描画は、中程度のスマホでも操作が滑らかに動くことを目指す（計測は後のステップで実施）。

## 7. 技術構成
- **フレームワーク**：React / Next.js
- **スタイル**：Tailwind CSS（配色とスペーシングは CSS 変数のトークンとして定義）
- **3D**：Three.js（必要に応じて CSS 3D を併用）
- **レスポンシブ**：スマホ幅（16pxの左右余白、横スクロールなし）を基準に組む。

- ドメイン・ホスティング先
